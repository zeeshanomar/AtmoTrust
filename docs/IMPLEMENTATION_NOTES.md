# Implementation notes

- The supplied repository had no application code or dataset. The six governing files are copied into `docs/` with their canonical names.
- One long Open-Meteo Archive request timed out; four short seven-day windows per location succeeded. `demo_v1` contains 672 genuine hourly gridded/location reanalysis frames for the five coordinates. Raw provider responses are cached under gitignored `data/raw/`. The package is never presented as a physical AWS feed. The preparation script retains a clearly labelled synthetic fallback for genuinely unavailable Archive access.
- Pressure is mean sea level pressure for all logical locations. The provider's `pressure_msl` field is normalized to `pressure_hpa`.
- The runtime uses a causal seasonal/peer expected baseline and a trained Isolation Forest. No regressor was added because the baseline is sufficient for the demo and avoids an unvalidated model.
- The backend is a single-process demo. Its active run and replay clock live in memory. SQLite records frames, incidents, injections, and actions; a restart creates a new disposable run. Both browser windows join the current backend run.
- The local server starts the prepared replay at 1× with 48 warm-up frames and over ten minutes of source frames available. Reset returns to that baseline paused. Uvicorn requires the explicit `websockets` dependency for actual browser publications.
- Live mode fetches all five locations from Open-Meteo current weather with a seven-second overall deadline. A failed fetch exposes an unavailable state. Replay remains intact. Faults can be scheduled on live observations as clearly labelled test copies; the original provider value remains in `raw_value`, and inference sees only the test value. A cached provider timestamp may be processed as a new test frame, without claiming a fresh provider measurement. The regional scenario remains replay-only. An initial live frame can use contemporaneous peers with limited historical context.
- The master document fixes the final scope at five logical locations. Rupnagar and Ludhiana were therefore not added in this local pass. Expanding the network requires updating its five-location scope and judge story before new data preparation, model training, and benchmarking.
- The Leaflet panel falls back to coordinate markers without tiles if OpenStreetMap tiles fail.
- `render.yaml` and `frontend/vercel.json` are deployment configuration only. No public deployment was attempted without a configured account/target.
- For split hosting, set Vercel `VITE_API_BASE_URL=https://<Render host>` and `VITE_WS_BASE_URL=wss://<Render host>` at build time, and set Render `ATMOTRUST_ALLOWED_ORIGINS=https://<Vercel host>`. The demo SQLite file is local to one Render process and is not durable without a configured persistent disk.
